# Open Source Boost Controller Using a ESP32-C3 SuperMini and a BMW N75 Boost Valve.  
The Code was mainly written by an LLM, since I do not posess the sufficient skills, please feel free to review it.
 
The controller sits between the Valves GND connection and the Chassis to switch Low at ~28hz via a PWM signal generated by a PID controller running on the ESP32.
![3D Render](/ob-img/pcb-render.png)
To set Parameters (PID and Boost) it runs a Webserver on it's own WIFI network. I might add physical controls too a future version, for now the aim of this project is to keep it as cheap and accessible as possible.

### BOM (THT unless Specified):
- ESP32-C3 SuperMini  
- IRLZ44N  
- TC4422  
- TIP2955  
- L7805  
- 6P JST-VH Horizontal Connector  
- 2x SMD 2020 WS2812B (not used in Code atm)  
- Various Resistors  
- 2x220uF 16V  
- 3x100nF Ceramic  
- 1N4007 Diode (at Boost Valve)  
- (Pin Sockets for ESP32)

Valve used at Wastegate: BMW N75 Boost Control Valve (on a CA18DET Engine). You have to hook up above mentioned flyback diode directly to the pins of the valve.

This is REV2.0 fixing the mistakes of my previous PCB design, it's currently not field tested.
