# Open Source Boost Controller w/ ESP32-C3 SuperMini.  
This is REV2.0 fixing the mistakes of my previous PCB design, it's currently not field tested. 

**The Code was mainly written by an LLM, since I'm extremely inexperienced with coding, please be advised that this is not in any way "safe" to hook up to your engine, please take a minute and review the code yourself and decide for yourself. If you find anything that you might want to change I'm more than happy to see a PR opened!**
speaking of code, the 2 LEDs are currently not in use.

The controller sits between the Valves GND connection and the Chassis to switch it at ~28hz via a PWM signal generated by a PID controller running on the ESP32.
To set Parameters (PID and Boost) it runs a Webserver on it's own WIFI network, which is kind of tedious, but I might add physical controls too a future version, for now the aim of this project is to keep it as **cheap and accessible as possible.**

### BOM (THT unless Specified):
- ESP32-C3 SuperMini  
- IRLZ44N  
- TC4422  
- TIP2955  
- L7805  
- 6P JST-VH Horizontal Connector  
- 2x SMD 2020 WS2812B (not used in Code atm)  
- Various Resistors  
- 2x220uF 16V  
- 3x100nF Ceramic  
- 1N4007 Diode (at Boost Valve)  
- (Pin Sockets for ESP32)

Valve used at Wastegate: BMW N75 Boost Control Valve (on a CA18DET Engine), although any suitable boost/mac valve should be fine to use. You have to hook up above mentioned flyback diode directly to the pins of the valve.

Link to my original reddit post from rev 1: https://www.reddit.com/r/esp32/comments/1vrntt0/i_made_a_boost_controller_with_a_esp32c3_first/
